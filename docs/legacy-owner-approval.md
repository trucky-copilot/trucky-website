# Owner approval only — restricted legacy provenance migration

This prepares step 1 of the supplied Base44 contract. It does not perform admin preview/execute, write provenance, change base44_user_id, charge Stripe or alter trials.

New page: /billing-link/legacy-approval. New POST: /api/billing/legacy-approval; GET exposes only enabled/signedIn/eligible/fresh booleans. Default OFF: LEGACY_OWNER_APPROVAL_ENABLED must be exactly true. Keep billing LIVE/access flags OFF. Uses existing TRUCKY_SERVER_SECRET; no new credential.

Pilot eligibility requires the existing BILLING_LINK_PILOT_GOOGLE_SUB and BILLING_LINK_PILOT_ORGANIZATION_ID to match the authenticated subject and the fixed contract organization. Member and organization targets are fixed server-side. Clients can supply only owner_consent:true, not a token, mode, identifier or destination. Same-origin enforcement precedes writes. Google ID token remains solely inside the encrypted HttpOnly NextAuth JWT and server-to-server request. A new NextAuth Google callback stamps googleAuthenticatedAt; old sessions must sign in again. The page requests account selection and max_age=0; Base44 must still verify cryptographic identity and token age (<=10 minutes). Local reauth timestamp is an additional safeguard, not a substitute for checking Google's token claims. The local 9-minute threshold leaves a clock/network margin.

Explicit checkbox required. No auto-submit, no retries after any submission. 200 is accepted only with code OWNER_APPROVAL_RECORDED. 409 does NOT establish that approval exists (can also mean failed checks). Unknown or lost responses require admin inspection. UI says 15 minutes from recorded approval; it does not invent an expiry supplied by the backend. No response body from Base44, token, consent payload or PII is logged.

Backend endpoint: migrateLegacyMembershipProvenance, mode owner_approval; no admin session is forwarded. Backend independently enforces owner identity, active membership, target and freshness; later admin action uses its own native session. Before enabling, operator must confirm PR #26 is published, migration disabled-by-default gate is coordinated, exact request/response matches and safe audit/one-use semantics implemented. Backend source has not been accessible to this Agent, so this PR does not approve its implementation.

Acceptance requires owner login on the canonical deployment domain and explicit consent, then operator confirmation of OWNER_APPROVAL_RECORDED and expiry without token storage. Only then admin preview/execute. No one should copy ID tokens from browser tools. Preview without credentials can verify the disabled UI but not actual consent execution. No production configuration or migration is changed by publishing this PR.
